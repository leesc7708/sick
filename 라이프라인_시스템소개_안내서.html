개요 · OverviewSheet 02

시스템 개요

라이프라인은 산업현장 근로자가 아플 때·다쳤을 때 현장에서 가장 먼저 여는 앱입니다. 응급 신호를 먼저 가려내 119·응급실로 연결하고, 작업 전 건강 상태와 사고를 관리자에게 바로 전달하며, 특수건강진단 서류를 QR 한 번으로 제출합니다. 한국어를 못 읽는 근로자도 모국어로 쓰고 한국어로 말할 수 있게 만든 웹 기반 통합 플랫폼입니다.

법으로 강제되는 의무

  • 산업안전보건법 — 특수건강진단, 작업 전 점검
  • 개인정보보호법 제28조의8 — 국외이전 동의

  • 의료 연결 — 진료과 · 병원 · 복용약

비진단 원칙 — 본 시스템은 의료 참고 정보와 응급 연결을 제공하며, 진단·처방을 하지 않습니다. 의료법·약사법 리스크를 설계 단계에서 회피하기 위한 제품 원칙입니다.

주요 기능 ① · 응급 대응Sheet 04

주요 기능 ① 응급 대응

응급은 판단보다 선별이 먼저입니다. 서버·AI가 죽어도 기기에서 항상 동작하는 1차 선별을 두고, 위험 신호가 잡히면 다른 화면을 거치지 않고 119·응급실 경로로 바로 전환합니다.

Red Flag

응급 신호 14항목 선별

  • 일반 8항목 — 흉통+호흡곤란, 벼락두통, 의식저하, 편측마비, 심한 알레르기 반응, 멈추지 않는 출혈, 고열+의식저하, 심한 복통
  • 현장 6항목 — 밀폐공간 어지럼, 화학물질 접촉, 고온 탈진, 추락·협착, 가스 흡입, 감전
  • 검출 즉시 응급 화면으로 강제 전환
  • 기기에서 검출 — 네트워크·AI 상태와 무관
Immediate Action

지금 할 일만 보여준다

  • 119 즉시 전화 — 홈 최상단 고정 버튼
  • 구급대 도착 전 대처 카드 (응급처치 안내)
  • 위치·증상·기저질환·복용약·알레르기를 한 화면에 정리해 구급대에게 제시
  • 구조자 안전 우선 경고 상시 표기
AED

심장충격기 위치 · 사용법

  • 전국 설치 12,280건 (지역 단위 조회)
  • 3단계 사용법 — 패드 부착 → 분석 중 손 떼기 → 쇼크 후 가슴압박 계속
  • 관리기관·연락처 표기, 출처와 변동 가능성 명시
  • 같은 화면에서 119 전화 동시 제공

응급 화면은 비면 안 된다 — 조회가 실패해도 “없음”으로 표시하지 않고, 장애 안내와 함께 119 경로를 반드시 같이 제시합니다. 설계 근거는 Sheet 10.

주요 기능 ② · 현장 안전 @workSheet 05

주요 기능 ② 현장 안전 @work

현장 모드에서만 열리는 기능군입니다. 근로자의 입력이 관리자 화면에 실시간으로 도달하는 것이 이 레인의 전부이며, 작업 전 점검 의무와 특수건강진단 서류 제출을 그대로 디지털화합니다.

Pre-work Check

작업 전 건강체크 실연동

  • 4문항 — 수면 6시간 이상 / 전날 음주 / 필요한 약 복용 / 어지럼·심한 피로
  • 작업 종류 선택 (밀폐공간·화학물질·고소 등)
  • 부적합 판정 시 관리자에게 즉시 전송
  • 관리자 화면에 수신 카드로 표시 · 확인 처리
Incident Report

사고·이상 1탭 보고 데모 단계

  • 유형 선택 즉시 해당 응급처치 카드 + 가까운 응급실 표시
  • 현재 위치(GPS) 자동 첨부 · 상황 메모 선택
  • 관리자·보호자 전송 — 사내 채널 연동은 다음 단계
  • 보고 이력은 지난 기록에 누적
Crew Alert

현장 그룹 긴급 알림 실연동

  • 오늘 배정된 현장 그룹을 앱이 자동 인식
  • 홈에서 관리자에게 긴급 알림 1탭 전송
  • 배정 그룹이 없으면 119 안내로 즉시 대체 — 조용히 실패하지 않음
  • 관리자는 현장 그룹·긴급 관리 화면에서 일괄 확인
Site Documents

현장 서류함 · QR 제출

  • 특수건강진단·건설기초안전교육·화관법 등 분류별 보관
  • 카메라 촬영 / PDF·파일 / 사진 보관함에서 등록
  • 검진일·유효기간 관리 — 만료 임박·만료 자동 표시
  • 현장 입구에서 QR로 제시 만료·접근제어는 서버 연동 후
주요 기능 ③ · 의료 연결Sheet 06

주요 기능 ③ 의료 연결

“어느 과를 가야 하는지”, “지금 받아주는 응급실이 어디인지”를 실시간 공공 데이터로 답합니다. 진단이 아니라 연결이 목적이며, 모든 안내에 참고용임을 함께 표기합니다.

Department Guide

어느 과 가야 하나요?

  • 증상을 편한 문장으로 적으면 진료과 안내
  • AI 안내 / 규칙 기반 간이 안내를 출처로 구분 표기
  • 국외이전 미동의 시 AI 미사용 — 규칙 기반만 동작
  • 안내 직후 해당 진료과 병원 찾기로 연결
Find Care

  • 권역외상센터 20 — 서버 캐시 + 앱 동봉 스냅샷 2중 방어

Summary Card

진료 요약 카드

  • 모국어 + 한국어 병기 — 근로자도, 의료진도 읽을 수 있게
  • 화면 제시 / 공유 텍스트 / PDF 출력
  • 한국어 사용자에게는 중복 없이 1회만 표기
My Medicines

내 복용약 · 지난 기록

  • 복용 중인 약·알레르기 메모를 목록으로 보관
  • 병원·약국에 그대로 제시 — 구두 설명 오류 제거
  • 지난 기록 — 증상·사고·작업 전 체크 이력 열람
  • 저장값은 한국어 기준, 표시만 번역 — 기존 기록 호환 유지

Bilingual

병기 원칙

  • 의료진에게 제시하는 화면은 모국어로만 번역하면 안 된다
  • 진료 요약 카드·공유 텍스트·PDF 모두 병기
  • 개수는 긴급 (3) 형태로 — 조사·어순이 언어마다 달라 문자열을 이어붙이면 자연스러운 문장이 안 나온다
Verification

번역 누락 검사기

  • 한 언어에만 키를 빠뜨리면 조용히 한국어로 폴백 — 컴파일·빌드로는 안 잡힌다
  • 자체 검사기로 7개 언어 키 일치 + 코드가 쓰는 키의 정의 여부 + 이름 치환자 일치까지 검사
  • 실패 시 종료코드 1 — CI에 그대로 연결 가능

현재 단계 — 번역은 AI 1차 생성본입니다. 화면 라벨·안내 문구라 위험도는 낮으나, 정식 출시 전 태국어·베트남어 원어민 검수를 권장합니다. 응급·투약 지시문에는 사용하지 않습니다.

신뢰성 설계 · ReliabilitySheet 10

신뢰성 설계 — 실패를 숨기지 않는다

응급 앱에서 가장 위험한 장애는 장애처럼 보이지 않는 장애입니다. 실제 운영 중 겪은 11일간의 전면 중단에서 얻은 원칙을 문서가 아니라 코드로 고정했습니다.

원칙 01

실패를 빈 결과로 폴백하지 않는다

  • 조회 실패를 “결과 0건”으로 돌려주면 총체적 장애가 “그 지역엔 원래 없나 보다”와 구분되지 않는다
  • 모든 조회가 성공 / 실패 / 오래된 데이터를 구분된 값으로 반환
  • 실패 시 전용 안내 + 119 경로 + 다시 시도
원칙 02

오래된 정보를 최신인 척하지 않는다

  • 상류 장애 시 캐시·스냅샷으로 화면을 채우되
  • “저장된 목록입니다 · 0000-00-00 기준” 배지를 함께 표시
  • 이송 병원 목록처럼 비면 안 되는 화면은 기준일을 밝혀서라도 제시
원칙 03

안전장치는 같은 패턴 전부에 적용한다

  • 타임아웃·재시도를 2종에만 붙여두어 나머지 4종이 다음 장애가 됐던 사례
  • 이후 공공 API 6종 전부 동일 헬퍼 경유로 통일
  • 재발방지는 할 일 목록이 아니라 코드·스크립트로 고정
진단 순서 — 같은 증상 재발 시
  • 응답 주체를 먼저 본다 — 우리 코드가 만들 수 없는 형식이 오면 그 시점에 “코드 미실행”이 확정된다
  • 서로 다른 키를 쓰는 기능이 동시에 죽으면 키 문제가 아니다 — 공통 인프라를 본다
  • 실패까지 걸린 시간을 본다 — 10초대면 연결 자체가 안 맺어진 것, 즉시 실패면 주소 해석 실패
운영 중 배운 것
  • 장애 조사용 폴링이 장애를 유발한다 — 조사 중 과도한 재시도로 상류에서 차단된 사례. 감시 주기를 줄이는 것이 복구를 앞당긴다
  • 거의 안 바뀌는 목록을 매번 실시간 조회하지 않는다 — 전국 20곳 목록 때문에 화면이 비는 일은 없어야 한다
  • 감시는 플랫폼 밖에서 돌아야 한다 — 결제·인프라가 꺼지면 그 안의 감시도 함께 죽는다
시스템 도입 장점Sheet 11

시스템 도입 장점

01

골든타임 확보

응급 신호 선별 → 119 → 실시간 가용병상 응급실까지 한 화면 안에서 이어집니다. 어디로 갈지 찾는 시간이 사라집니다.

02

법적 의무 이행

중대재해처벌법·산업안전보건법이 요구하는 작업 전 점검과 특수건강진단 서류 관리를 기록으로 남깁니다.

03

실시간 현황 파악

부적합 판정과 긴급 알림이 관리자 화면에 바로 도달합니다. 보고를 기다리지 않고 현장 상태를 봅니다.

04

언어 장벽 제거

7개 언어 화면과 한국어 음성으로 통역 없이 증상을 전달합니다. 오해로 생기는 의료·안전 비용이 줄어듭니다.

05

서류 행정 절감

검진 결과의 반복 제출·분실·재발급이 QR 한 번으로 끝납니다. 현장 입장 시 확인 시간도 줄어듭니다.

06

낮은 도입 부담

설치·앱스토어 심사 없이 웹으로 즉시 배포됩니다. 공공 데이터는 무료이고 서버 비용도 낮아 변동원가가 거의 없습니다.

비용 효과 — 중대재해 1건의 직·간접 비용은 통상 수억 원 이상입니다. 정량 효과는 사업장별로 다르지만, 1건을 예방하는 것만으로 연 운영비를 크게 상회합니다.
